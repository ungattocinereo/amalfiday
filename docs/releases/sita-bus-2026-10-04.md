## Production and rollback

Production PDFs are served independently by Caddy from `/srv/amalfiday/files`.
They are not stored in `public` or rebuilt by Astro. Unlisted legacy files
`BUS-5111-Scala-Ravello.pdf` and `BUS-5121R-AMALFI-POGEROLA.pdf`, ferry PDFs, and
the Amico shuttle are outside this update.

Release directory: `/srv/amalfiday/.release-sita-bus-20261004`.
Backup archive: `/home/greg/_backup/2026-10-04-amalfiday-sita-bus/source-and-pdfs-before.tar.gz`.

The release keeps `before-dist`, the three original source files, four replaced
PDFs, before/after PDF hashes, build logs and the official-file manifest. The
isolated build preserves production calendars and both Google verification
files. The deploy mutex and a temporary pause of `amalfi-rebuild.service` prevent
concurrent rebuilds; the service is restored afterwards.

To roll back, coordinate with the deploy mutex and rebuild service, restore
the original source/PDF files, and atomically exchange the retained `before-dist`
with the live output, preserving the displaced version. The two newly added PDF
filenames can remain available. No Caddy configuration change is involved.

Source edits and the provenance manifest are committed to `main` and applied
to the production checkout so the next GitHub deploy retains them. The deploy
mutex remains held while publishing the source commit and activating the site.
The exact source revision is retained in `source-commit.txt` in the release.
