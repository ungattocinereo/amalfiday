## Restore

Use the published checkpoint to return to the complete version approved on
30 September, or the previous checkpoint to undo this release. Preserve the
current output before restoring a retained VPS copy through an atomic directory
exchange with `/srv/amalfiday/dist`.

Coordinate the source revision and `amalfi-rebuild.service` with the selected
checkpoint so a later Ghost rebuild keeps the restored version. Preserve
server-only files, production environment, verification pages and calendars.
Keep the contact API and Caddy routing unchanged. A static-output rollback does
not require restarting them.

For a fresh build, fetch the chosen GitHub tag into a separate checkout and follow
[the static deployment guide](../deploy-static.md). Build and verify the output
before activating it. Retain the existing checkpoints from 29 September.
