# Brand assets

`getyourguide-logo.svg` is the unmodified coral logo from the official
[GetYourGuide Press Center](https://www.getyourguide.press/download-center),
downloaded on 2 October 2026 from its
[brand logo asset](https://cdn.prod.website-files.com/637b6b9b9e498750e58dca08/637b6b9b9e4987d97a8dca35_brand-logo.svg).
It identifies the source of a client review, without implying endorsement.

The existing `getyourguide.png` is a separate approved-supplier badge used by the
catalogue. Client reviews use the standalone logo instead.
